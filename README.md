# MNIST Digit Classification Using Neural Networks

## Project Overview
Built a neural network using TensorFlow and Keras to classify handwritten digits (0–9) from the MNIST dataset.

## Tools & Libraries
- Python
- NumPy
- Matplotlib
- TensorFlow / Keras
- Scikit-learn

## Workflow
- Explored and visualized the dataset.
- Normalized pixel values to the range 0–1.
- Built a neural network using Dense layers, ReLU, and Softmax.
- Trained the model for 10 epochs.
- Evaluated performance using accuracy and loss.
- Analyzed misclassified images and visualized the confusion matrix.

## Evaluation
Evaluated the model on the test dataset and analyzed its classification errors.

## Key Skills
Neural Networks, Deep Learning, Image Classification, Model Evaluation, Error Analysis.
